# Archived planning docs

These are **historical** planning docs, kept for reference only. They predate the
trip-model overhaul (departures/batches as the single source of truth for
date/price/seats, occupancy pricing, the booking→departure contract) and the audit
fixes in `AUDIT.md`. Where they conflict with the current code, **the code wins** —
do not treat these as a current spec.

- `v2-redesign.md` — original v2 public-site redesign plan (reference prototype in `lovable-code/`).
- `v2-admin-redesign.md` — original v2 admin redesign plan (reference designs in `uxpilot-admin/`).

For the current state and outstanding work, see `AUDIT.md` at the repo root.
